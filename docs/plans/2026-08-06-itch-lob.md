# Nasdaq TotalView-ITCH 5.0 Feed Handler + LOB + ML — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A C++ feed handler that parses raw gzipped ITCH 5.0 historical files, reconstructs a price-level limit order book, produces reproducible throughput/latency/validation numbers, and exports book data that a Python ML layer (OFI midprice + queue-position fill probability, XGBoost) consumes directly.

**Architecture:** Single-threaded C++20 hot path: chunked zlib inflate → 2-byte big-endian length framing → switch-dispatch parser → hash-map order store + sorted-vector price-level books for a small tracked-symbol set. Two binary export streams (L5 snapshots, order lifecycles) feed a Python venv layer that computes Cont-Kukanov-Stoikov OFI and trains XGBoost on two targets across a two-day train/test split.

**Tech Stack:** C++20 (Apple clang 17), zlib (system), Makefile (no CMake on machine; zero-dep build), Python 3.13 venv: numpy, pandas, xgboost, scikit-learn, matplotlib, pillow (GIF only).

**Plan status/provenance:** Written 2026-08-06 *before implementation*, from the official spec PDF (fetched 2026-08-06 from nasdaqtrader.com, 36 pp.) and a verified listing of `emi.nasdaq.com/ITCH/Nasdaq%20ITCH/`. Message layouts below are transcribed from the spec, not from memory. Numbers marked "expected" are pre-registered guesses, not results. Results live in `validation.json`, benchmark output, and the README — never in this plan.

## Global Constraints

- Historical-file framing: each message is preceded by a 2-byte big-endian length (per project instruction; the live feed's MoldUDP64 framing is not used here). Verify empirically against the first bytes of real data before trusting.
- All integer fields big-endian, unsigned. Prices are Price(4) uint32 (implied 4 decimals) except MWCB levels Price(8). Timestamps are 6-byte nanoseconds since midnight. Alpha fields are space-padded ASCII.
- Never write the decompressed day to disk (~16 GB/day raw). Stream-decompress; peak disk ≈ two gzipped days ≈ 10.4 GB.
- Parse **every** message on the wire; maintain books only for tracked symbols. Memory stays bounded via locate-code filtering at add time.
- Every number in the README must be produced by a command listed in the README. No claim without a measurement.
- Benchmarks unthrottled; replay/viewer entirely separate from benchmarks.
- Phase gate: Phase 2 does not start until Phase 1 validation reconciles.
- Data days: dev/train = 01302019, test = 03272019 (both Wednesdays; delete .gz files if disk pressure requires, after exports are produced).
- Tracked symbols (8, liquid, Jan-2019-era tickers): AAPL, MSFT, AMZN, NVDA, AMD, INTC, FB, TSLA. All Nasdaq-listed, so closing-cross prices are official closes — externally checkable against public records.

## Wire Format (transcribed from spec §1.1–1.8; offset 0 = the 1-byte type; length includes it)

| Type | Message | Len | Fields parsed on hot path |
|---|---|---|---|
| S | System Event | 12 | ts(5,6), event_code(11,1): O,S,Q,M,E,C |
| R | Stock Directory | 39 | locate(1,2), stock(11,8) → locate→symbol table |
| H | Stock Trading Action | 25 | locate, ts, state(19,1): H,P,Q,T |
| Y | Reg SHO | 20 | counted only |
| L | Market Participant Position | 26 | counted only |
| V | MWCB Decline Level | 35 | counted only (Price(8) ×3) |
| W | MWCB Status | 12 | counted only |
| K | IPO Quoting Period | 28 | counted only |
| J | LULD Auction Collar | 35 | counted only |
| h | Operational Halt | 21 | counted only |
| A | Add Order | 36 | locate, ts, ref(11,8), side(19,1), shares(20,4), stock(24,8), price(32,4) |
| F | Add Order w/ MPID | 40 | as A + mpid(36,4) |
| E | Order Executed | 31 | locate, ts, ref, exec_shares(19,4), match(23,8) |
| C | Order Executed w/ Price | 36 | as E + printable(31,1), exec_price(32,4) |
| X | Order Cancel | 23 | locate, ts, ref, cancelled_shares(19,4) |
| D | Order Delete | 19 | locate, ts, ref |
| U | Order Replace | 35 | locate, ts, old_ref(11,8), new_ref(19,8), shares(27,4), price(31,4) |
| P | Trade (non-cross) | 44 | locate, ts, shares(20,4), price(32,4), match(36,8) — never touches book |
| Q | Cross Trade | 40 | locate, ts, shares(11,8), price(27,4), cross_type(39,1): O,C,H |
| B | Broken Trade | 19 | counted only (book-irrelevant per spec §1.5.3) |
| I | NOII | 50 | counted only |
| N | RPII | 20 | counted only |
| O | DLCR Price Discovery | 48 | counted only |

Unknown type byte → hard error (stop, report byte offset): silent skips would corrupt everything downstream. Framed length must equal the spec length for the type, else hard error.

Semantics that matter (spec §1.4–1.5): modify messages are cumulative; an order is dead when display shares reach zero; U = delete old ref + fresh add under new ref (side/symbol inherited from the original, which the spec says firms must retain); C executions marked non-printable ("N") are excluded from volume tallies (bulk-printed later in Q) to avoid double counting; P messages are hidden-liquidity matches — they never touch the displayed book but count toward volume; Q cross volume counts once.

## Phase 1 — parser, book, numbers (hard gate)

### Task 1: framing reader + message counter
**Files:** `src/messages.hpp`, `src/reader.{hpp,cpp}`, `src/itch_parse.cpp`, `Makefile`
**Produces:** `Reader::next()` → `{const uint8_t* msg, uint16_t len}` view valid until next call; chunked zlib inflate (8 MB output buffer), memmove tail handling for messages spanning chunk boundaries.

- [ ] Verify framing empirically: hexdump the first 64 decompressed bytes; expect a 2-byte BE length then `'S'` system event with sane timestamp. Record what the length prefix actually counts (with vs. without type byte) in DECISIONS.md before writing the parser loop.
- [ ] Full-day message-count smoke run: per-type counts + total; distribution sanity (A/D/U/X/E dominate). The total is the denominator for every benchmark.
- [ ] Length-consistency check across the whole day: framed length equals spec-table length for every message, else hard error with offset.

### Task 2: order book
**Files:** `src/book.{hpp,cpp}`, `src/handler.{hpp,cpp}`, `tests/book_test.cpp`
**Interfaces produced (Phase 2 depends on these):**
- `struct Order { uint16_t locate; char side; uint32_t price; uint32_t shares; }` in `unordered_map<uint64_t, Order>` (tracked locates only; reserve generously).
- `struct Level { uint32_t price; uint32_t shares; uint32_t count; }`; per side `std::vector<Level>` sorted best-first (bids desc, asks asc); linear insert from front (best-at-front is the hot case).
- `Book::{add, execute, cancel, del, replace}`; each reports whether top-5 changed (drives snapshot export).
- Accessors: `best_bid()`, `best_ask()`, `depth5(side)`.

- [ ] U handled as del(old_ref) + add(new_ref) inheriting side/locate from the stored order.
- [ ] E/C decrement stored order shares; erase order and empty levels at zero.
- [ ] `make test`: scripted sequences with known outcomes — add both sides, partial exec, full exec, partial cancel, delete, replace (price move loses queue), non-printable C, P (book untouched) — assert exact levels after each.

### Task 3: validation counters (what makes the numbers citable)
**Files:** `src/handler.{hpp,cpp}` (`--validate` mode)
Exact definitions (these go verbatim into the README):
- **Execution match rate** = fraction of E/C messages on tracked locates that apply cleanly to the reconstructed book: order ref present, remaining shares ≥ executed shares, and (for E) execution implicitly at the stored order's price. Target 100%; every mismatch logged with file offset.
- **Modify integrity** = same, for X/D/U on tracked locates. Target 100%.
- **Book sanity** = count of crossed-book instants (best bid ≥ best ask) during the regular session (after opening cross Q, before closing cross Q, excluding halt windows from H messages) per tracked symbol. Expect 0; report actual.
- **Volume reconciliation** — internal: per tracked symbol, Σ E.shares + Σ C.shares(printable=Y) + Σ P.shares + Σ Q.shares, cross-checked against an independently accumulated per-locate tally; external: closing-cross (Q, type C) price vs the official close from public records (exact match expected — Nasdaq closing cross *is* the official close for Nasdaq-listed), and Nasdaq-venue volume vs consolidated public volume reported as a **ratio with the venue caveat** (Nasdaq is one venue of ~16; a match is impossible by construction and will not be claimed).
- [ ] Emit `validation.json` with every number, so the README quotes a file, not prose.

### Task 4: benchmarks
**Files:** `src/hist.hpp`, modes `--bench`, `--latency`
- Throughput pass (`--bench`): no per-message timers. Report (a) end-to-end wall-clock msgs/s including gzip inflate + I/O, and (b) parse+book msgs/s = total msgs / Σ(per-chunk processing time), chunks timed with `mach_absolute_time`. State hardware (Apple M4, 10-core, 16 GB, macOS 15) and that the hot path is single-threaded.
- Latency pass (`--latency`): separate run; per-message timer pairs around parse+book-update only (excludes inflate); fixed-bin histogram (1 ns bins to 16 µs + overflow) → p50/p99/p99.9. Measure and state timer overhead (median of back-to-back timer-call deltas) alongside — do not silently subtract it.
- [ ] Each pass run 3×, median run reported.

### Task 5 — the gate
- [ ] `--validate` on 01302019: 100% execution + modify match and 0 unexplained crossed instants. Any unexplained mismatch **blocks Phase 2** until diagnosed. Documented, understood exceptions (e.g. crossing inside a halt window) are acceptable only with the explanation written into validation output.

## Phase 1.5 — replay + viewer (only after the gate)

**Files:** `src/itch_replay.cpp`, `scripts/render_gif.py`
- Replay honors inter-message timestamp deltas scaled by `--speed N` (sleep-based pacing; coarse, and stated as such — this is a demo, never a benchmark).
- ANSI terminal viewer: top-10 levels for one symbol, bid/ask ladders, spread, last trade, session clock, message counter; redraw ≤ 30 fps.
- [ ] `--frames-dir` dumps periodic plain-text frames; `render_gif.py` (pillow, venv) renders `docs/assets/book.gif` (~10 s of AAPL around 09:30).

## Phase 2 — ML on the book's own output

### Exports (one additional full-day pass with `--export`, after the gate)
1. `snapshots.bin` — fixed 96-byte records, one per event changing top-5 of a tracked book: `u64 ts_ns, u16 sym, u8 reason, u8 _pad, u32 bid_px[5], u32 bid_sz[5], u32 ask_px[5], u32 ask_sz[5]`. Read with a numpy structured dtype; expected O(1–2 GB)/day.
2. `orders.bin` — fixed-size records, one per tracked **resting add within 5 ticks of the same-side touch**: `u64 ts_add, u64 ref, u16 sym, u8 side, u8 dist_ticks, u32 px, u32 sz, u32 queue_ahead_shares, u32 level_sz_before, u32 same_depth5, u32 opp_depth5, u32 spread_at_add, u8 outcome, u8 _pad[3], u64 ts_outcome, u32 exec_shares` where outcome ∈ {F filled(≥1 sh), X cancelled/deleted, R replaced, U alive at EOD}. Labels come free from the stream — the L3-only advantage.

### Task 6: OFI + midprice (pre-registered: expect weak; report honestly)
- CKS OFI at L1 per event n: `e_n = 1{Pb_n≥Pb_{n−1}}·qb_n − 1{Pb_n≤Pb_{n−1}}·qb_{n−1} − 1{Pa_n≤Pa_{n−1}}·qa_n + 1{Pa_n≥Pa_{n−1}}·qa_{n−1}`; `OFI(t,h) = Σ e_n over (t−h, t]`.
- Sample every 500 ms per symbol, 09:35–15:55 only. Features (all strictly from ≤ t): OFI at {100 ms, 1 s, 5 s}, spread, L1 imbalance, depth-5 imbalance, 1 s and 5 s trailing mid returns, signed trade volume 1 s. Target: Δmid(t → t+1 s) in ticks. XGBoost regressor, depth ≤ 6, early stopping on a *train-day tail slice* (never the test day).
- Report out-of-sample R² on 03272019. **Pre-registered: R² ≈ 0.001–0.02 is the honest range. R² > 0.05 ⇒ assume leakage; checklist: backward-only joins, target window not overlapping feature window, sampling not aligned to target events, no normalization fit on test.**
- [ ] Feature-importance plot → docs/assets/.

### Task 7: fill probability (the interesting half)
- One row per orders.bin record; drop outcome=R rows (replacement makes continuation ambiguous — stated in README). Label = (outcome==F). Features at insertion only: queue_ahead_shares, dist_ticks, order size, spread_at_add, level_sz_before, depth-5 imbalance, side, OFI-1s at insertion (backward-only merge_asof from snapshots), time-of-day bucket.
- XGBoost classifier. Report test-day ROC-AUC + calibration curve (docs/assets/). Context baseline: logistic regression on queue_ahead + dist_ticks alone. **Pre-registered: AUC ≈ 0.70–0.85 plausible.**
- [ ] Leakage guard assertion: every joined feature timestamp ≤ ts_add. Train = 01302019, test = 03272019, no state crosses the day boundary.

### Task 8: README + publish
- README order: one-paragraph what-it-is → measured-numbers table (throughput, p50/p99/p99.9, validation match rate, closing-cross check, R², AUC), each row with the exact command that regenerates it → GIF → design notes (~5 bullets) → limitations. Limitations must include verbatim: single venue — Nasdaq is a minority of total US equity volume; the other ~15 exchanges plus off-exchange flow are invisible here; sample dates are month-end and may be atypical sessions. Plus: one train day / one test day, 8 symbols, historical-file framing (not MoldUDP64), coarse replay pacing.
