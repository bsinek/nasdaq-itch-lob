# Decisions

- **2026-08-06 — Independent audit + fixes.** Three fresh-context auditors (C++/spec conformance, ML leakage, claim traceability) reviewed the repo before release. No finding invalidated a headline number; fixes applied: reader rejects frames < 12 bytes (closed an OOB path on malformed input that silently bypassed the hard-error guarantee), corrupt/truncated input exits 2 cleanly, U replace emits one post-replace snapshot (was two, including a phantom intermediate state), level-share deficits are counted not masked, fills OFI join made exclusive `[t-1s, t)` (an order's own insertion snapshot shares its nanosecond and was previously included), replaced-before-fill orders kept as unfilled instead of dropped (sample membership no longer conditions on outcome), midprice early-stopping switched to a true per-symbol chronological tail (the old comment claimed this; the code did a symbol-blocked cut), Hist::pct uses nearest-rank ceil. All export-derived and model numbers re-measured after these changes; README updated to the re-measured values. Plan-vs-built deviations noted: decompressed day ≈ 11.2 GB not the planned ~16 GB estimate; "signed trade volume 1 s" midprice feature not implemented; CLI uses bare subcommands not `--bench/--latency`; book/handler are header-only.

- **2026-08-06 — Framing.** Historical `*.NASDAQ_ITCH50` files: each message is prefixed by a 2-byte big-endian length whose value equals the spec-table message length *including* the 1-byte type. Basis: hexdump of first bytes of 01302019 day (`00 0c 53 …` = len 12 'S', then `00 27 52` = len 39 'R'); parser hard-errors on any message whose framed length ≠ spec length, so the full-day run is the exhaustive check.
- **2026-08-06 — Build system.** Plain Makefile + Apple clang, zlib from the system. Chose because the machine has no CMake and the project needs zero C++ dependencies; revisit only if the repo grows platform targets.
- **2026-08-06 — Repo root.** Repo root is this folder (`nasdaq-itch`), GitHub name `nasdaq-itch-lob` (Ben's call, 2026-08-06).
- **2026-08-06 — Order store.** `std::unordered_map` for order ref → order, tracked symbols only. Chose simplicity first; measure before optimizing (a flat open-addressing map is the known next step if latency numbers disappoint).
- **2026-08-06 — Timer.** `clock_gettime_nsec_np(CLOCK_UPTIME_RAW)` (mach counter). Apple-Silicon counter granularity is coarse (~42 ns on M-family; measured value reported by the latency benchmark itself). Percentiles are reported at that granularity with the exact aggregate mean alongside; timer overhead measured and stated, never silently subtracted.
- **2026-08-06 — Latency definition.** Per-message latency = field decode + dispatch + book update (`Handler::on_message`), excluding gzip inflation and 2-byte framing. Rationale: inflate is amortized I/O, not per-message work; a live handler would receive framed packets. Stated in README.
- **2026-08-06 — Tracked symbols.** AAPL MSFT AMZN NVDA AMD INTC FB TSLA (8 liquid Nasdaq-listed names as of the 2019 sample dates; FB not yet META). Nasdaq-listed only, so closing-cross prices are official closes → exact external check.
- **2026-08-06 — Repo root rename.** Folder renamed to `nasdaq-itch-lob` to match the GitHub repo (Ben's call, 2026-08-06); supersedes the earlier repo-root note.
- **2026-08-06 — Replay dashboard panes.** Kept: mid sparkline, 1s OFI gauge, candles + volume profile (traded shares by price, aggressor-split, shared price axis), ladder, tape with aggressor arrows (gray `·` = hidden-order prints, aggressor unknowable; excluded from the profile). Tried and dropped: depth heatmap (price × time × resting size), both absolute- and mid-anchored variants — legible only to practiced book-readers at terminal resolution, and the absolute variant blanks whenever price trends out of the visible band (Ben's call after trial GIFs, 2026-08-06).
- **2026-08-06 — Fill-label scope.** Order-lifecycle rows recorded only for resting adds within 5 ticks of the same-side touch, during regular session, symbol trading (state T) and post-opening-cross. Outcomes: F filled(≥1 sh), X cancelled/deleted unfilled, R replaced unfilled, U alive at EOD. Replaced rows are dropped from the ML sample (continuation ambiguous); stated in README.
